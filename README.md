# Fit-Finder

**Fit-Finder** is a responsive web platform that helps users discover gyms, explore gym services, and manage their fitness journey. Gym owners can manage their gyms, classes, and track engagement through a user-friendly dashboard.

---

## Features

### For Users
- **Gym Discovery**: Browse gyms by location, workout style, or membership type.
- **Detailed Gym Profiles**: Access photos, descriptions, hours, and facilities.
- **Reviews & Ratings**: Read feedback from other users.
- **Search & Filter**: Quickly find gyms with specific amenities.
- **Personalized Experience**: Save favorite gyms and track engagement.

### For Gym Owners
- **Dashboard Management**: Update gym details, pricing, and schedules.
- **Track Engagement**: Monitor how users interact with your gym profile.
- **Manage Classes & Events**: Schedule sessions and special events.
- **Reports & Insights**: Access analytics for data-driven decisions.

---

## Technologies Used
- **Frontend**: HTML5, CSS3, Tailwind CSS, JavaScript
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop
- **Animations**: Scroll reveal, card hover effects, dynamic stats
